# 🚀 AutoDataMining Studio — Hugging Face Spaces

**AutoDataMining Studio** adalah antarmuka web no-code berbasis Streamlit untuk mempermudah mahasiswa, dosen, dan peneliti dalam menjalankan seluruh tahapan data mining dan pembelajaran mesin tanpa perlu menulis kode rumit.

## 🌟 Fitur Utama di Hugging Face Spaces:
1. **5 Pilar Data Mining Lengkap:**
   - 🎯 Klasifikasi (*Classification*)
   - 📈 Regresi (*Regression*)
   - 🔍 Pengelompokan (*Clustering*)
   - 🛒 Analisis Keranjang Belanja (*Market Basket / Association Rules*)
   - 🚨 Deteksi Anomali & Penipuan (*Fraud / Anomaly Detection*)
2. **Dataset Edukasi Bawaan (1-Klik):** Langsung coba dengan data kelulusan mahasiswa, harga rumah, segmentasi nasabah, transaksi belanja, atau deteksi penipuan.
3. **Unggah Data Sendiri:** Drag-and-drop file CSV atau Excel Anda.
4. **Perbandingan Algoritma Otomatis (Leaderboard):** Membandingkan belasan algoritma scikit-learn secara objektif dengan cross-validation.
5. **Diagram Alur Pipeline Visual:** Flowchart arsitektur data mining untuk slide presentasi sidang skripsi.
6. **Kesimpulan Naratif Bahasa Indonesia:** Otomatis mendeteksi overfitting dan menyusun draf kalimat pembahasan skripsi.
7. **Penyetelan Hyperparameter Otomatis:** Optimalkan model pemenang dengan 1 klik tanpa *data leakage*.
8. **Ekspor Skripsi & LaTeX:** Salin tabel baku Bab IV Skripsi atau kode Overleaf LaTeX secara instan.
9. **Inferensi Langsung:** Uji coba prediksi data baru langsung dari web browser.
